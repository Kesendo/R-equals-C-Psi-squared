# Boundary/summed round: the two-row reflection as five explicit palindromic polynomials, and the obstruction sharpened

Scratch, local-only (`_rb_bnd*.py`). Run from repo root, `PYTHONIOENCODING=utf-8`. All arithmetic exact
over ℤ. Consolidated gate: `python simulations/_rb_bnd_gate.py` (~1 min build, prints `ALL GREEN`).
Builds on `_rb_summed.py` (Xc, Yc, Fk, TAILS) and `f133_w_closed_form.build_halves`.

Target (given): prove in-wall the affine translation `F_k(m+44) = −F_k(m)`, equivalently (via the
PROVEN oddness `F_k(−m) = −F_k(m)`) the reflection `F_k(m) = F_k(44−m)`, `m ∈ [12+2k, 32−2k]`,
live content `k = 0..4` (`k=5` vacuous).

## Headline

The two-row law is a **finite** object (only `k = 0..4` are live). Every live row's generating
polynomial has an **explicit factored closed form, each manifestly palindromic about `j = 5`**. That
is a complete elementary proof of the stated finite identity. The *structural* proof (an
affine-character reason that would generalize to the full `n_λ` program) stays **BLOCKED**, now at a
sharpened obstruction: the coefficient array's symmetry group is **exactly** `S₆ × ℤ₂(total-neg)`, the
44-translation provably lies **outside** it, and the telescope/boundary route the resumption point
hoped for **collapses to oddness** (shown constructively). So the surviving "summed boundary" idea is
closed as negative; what remains open is genuinely a theta/affine-character statement, unchanged in
kind from the Schur round's conclusion.

## The chain

### L0 — unsorted-antisymmetric form (PROVED, gate 0/258)
Because `Xc` is `S₆`-antisymmetric, the sort+sign in `F_k` folds in:
`F_k(m) = Σ_{ε∈{±1}⁵} sgn(ε)·Xc(m, ε₁(2k+10), ε₂·8, ε₃·6, ε₄·4, ε₅·2)`  (0/258 vs `Fk`).
This is the clean form everything below uses (`tail_k = (2k+10,8,6,4,2)`).

### L1 — single-variable reduction (definitional)
Writing `t₁ = e^{ix₁/2}` and extracting the coord-2..6 tail monomial of `X = Dhat·∏₃₁`,
`F_k(m) = [t₁^m] Ψ_k(t₁)`, `Ψ_k(t₁) := Σ_ε sgn(ε)·(tail-slice ε∘tail_k of X)(t₁)`.
Target ⟺ **`Ψ_k(t₁)` is self-reciprocal about `t₁^{22}`** on its positive support
(`Ψ_k(t₁) = t₁^{44}Ψ_k(1/t₁)` restricted to `m>0`). The `44 = 2·22` becomes: the positive support runs
`[12+2k, 32−2k]`, midpoint `22`, k-independent.

### L2 — the finite two-row law, PROVED by explicit closed forms (gate 0/5 + palindromy 0/5)
All live rows, generating polynomial `P_k(q) = Σ_j n_{(j,k)} q^j`, `j = (m−12)/2`:

| k | P_k(q) factored | window coeffs {j: n} |
|---|---|---|
| 0 | `−(1+q²)(1+q⁸)` | {0:−1, 2:−1, 8:−1, 10:−1} |
| 1 | `q(1−q⁴)²` | {1:1, 5:−2, 9:1} |
| 2 | `3q⁴(1+q²)` | {4:3, 6:3} |
| 3 | `−q³(1+3q²+q⁴)` | {3:−1, 5:−3, 7:−1} |
| 4 | `q⁴(1+q²)` | {4:1, 6:1} |

Each central factor is itself palindromic-about-0 (`1+3q²+q⁴` has coeffs 1,0,3,0,1), and the leading
monomial `q^{c_k}` centers it at `q⁵`; hence `P_k(q) = q⁵·S_k(q)` with `S_k(1/q)=S_k(q)` — **palindromy
by inspection**, no 36-way case check. `k=5` is vacuous (window `[22,22]`, `F_5(22)=0`, support below
window). **Independent cross-check**: `n_{(j,k)}` recomputed from the f133 sp(12) read-off
`n_raw(λ)/2` over the full two-row grid, `0/55` mismatches. So the stated finite identity is complete
and closed.

Note the defects (unpaired below-window support: k=1,3 at `m=10`; k=2 at `m=12`; k=4 at `m=16`) are
exactly the points whose reflection `44−m` sits past the wall `32−2k` — the READMEs' R_k defect,
reconfirmed. The palindromy is a **window** statement, not a global one (see L4).

### L3 — the symmetry group of the array, pinned exactly (gate)
From the source (`f133`): `X = Dhat·∏₃₁`, `Dhat = ∏_{u<v} sin((x_u−x_v)/2)` (type-A, `S₆`-antisym only,
NOT `W(B₆)`), 31 canonical sheets `L₁=+1`, deleted sheet = all-ones. Measured symmetries of the
coefficient arrays (on-support):
- `Xc(σν)=sgn(σ)Xc(ν)` (`S₆`-antisym); `Xc(−ν)=Xc(ν)` (total-neg **EVEN**, 1836/1836).
- `Yc` the same but total-neg **ODD** (`Yc(−ν)=−Yc(ν)`), the parity flip from the deleted 32nd sheet.

**Exactly these**: a single-coordinate sign flip is NOT a symmetry (data), so the group is
`S₆ × ℤ₂(total-neg)`, order `2·720` — the type-A Vandermonde group, not `W(C₆)`/`W(B₆)`.
Algebraic identity behind it: `x₁↦−x₁` composed with the tail-negation `σ_tail (x₂..x₆↦−x₂..x₆)`
equals **total negation**, so the coord-1 reflection alone is never a symmetry.
Gate: over ALL centers `a`, the coord-1-only reflection `ν₁↦a−ν₁` agrees with `±Xc` on at most
`108/1836` support points (a symmetry would need `1836/1836`) — **never a symmetry, any center**.

### L4 — the telescope/boundary route BLOCKED (constructive)
The relations the two-sided telescope furnishes on `Ĝ(a,c) := Σ_ε sgn(ε)·Yc(a, ε∘tail+c)` (with
coord-1 `a = m+c`) are:
- point-symmetry `Ĝ(a,c) = Ĝ(−a,−c)` (= L2/term-negation), and
- whole-line vanishing `Σ_{c odd} Ĝ(m+c,c) = 0` (every anti-diagonal sums to zero).

Both are **generated by oddness**. Folding `F_k(44−m)` through them returns
`F_k(44−m) = Σ_{c≥1}Ĝ(44−m+c,c) = [pt-sym] Σ_{c≤−1}Ĝ((m−44)+c,c) = [whole-line] −F_k(m−44)
= [oddness] F_k(44−m)` — a circular `0=0`. The point-symmetry maps the anti-diagonal `m` to `−m`
(oddness), never to `44−m`; the only map sending `m↦44−m` at the grid level is a **term bijection**
`(a,c)↦(c+22,a−22)`, which is exactly the GATE-4/6 DEAD c-pairing. Consistent with L3: the array has
no symmetry implementing a coord-1 translation, and the telescope furnishes only array-symmetry
consequences. **The 44-relation is not an identity of the array** (`26/225` global violations,
witness `k=0,m=12: F=−1, F(m+44)=0`); it lives only in the in-wall positive window. So no
telescope/boundary/summed argument built from these relations can reach it — the surviving idea is
refuted.

## What the 44 actually is (named, not proved)
`44 = 2·22`, `22 = midpoint([12+2k, 32−2k])` k-independent = (lower support edge `12+2k`) + (wall
`32−2k`) over 2. The wall `32−2k` is a PROVEN support bound. The reflection is therefore the statement
"the positive-support coefficients are palindromic between the lower edge and the wall." This is
**independent of** the proven oddness-about-0 (they act on disjoint half-lines, reconciled only by the
finite support) and of every array symmetry (L3). It is a pure in-wall support/coefficient fact — i.e.
exactly the theta / level-4 affine-C₆ character statement the level-pin and Schur rounds isolated. No
new symmetry closes it; a genuine special-function identity is required.

## Verdict
- **Stated finite identity `F_k(m)=F_k(44−m)`, k=0..4: PROVED / REDUCED** to five explicit factored
  palindromic polynomials `P_0..P_4` (L2), each palindromic by inspection, independently cross-checked
  (`n_raw/2`, 0/55). Complete and closed as a finite claim.
- **Structural (affine-character, generalizing) proof: BLOCKED** at the sharpened obstruction —
  array symmetry group is exactly `S₆ × ℤ₂`, the coord-1 translation-44 lies outside it (L3), and the
  telescope/boundary route collapses to oddness (L4, constructive). The residual is a theta/affine-C₆
  identity on the deleted-top-weight discriminant, unchanged in kind from `_rb_schur_README.md`.

Net: the surviving "summed boundary" route is closed negative; the finite law is re-proved more
transparently (explicit palindromic closed forms), which is the useful artifact for the `n_λ` hunt.
