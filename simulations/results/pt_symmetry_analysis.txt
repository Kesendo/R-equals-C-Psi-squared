1b. Linear vs anti-linear
────────────────────────────────────────────────────────────────────────

  Π is a MATRIX acting on coefficient vectors in Pauli basis.
  Π(αv) = α·Π(v) for all complex α. No conjugation involved.
  Therefore: Π is LINEAR.

  Consequence: {Π, L_c} = 0 is a linear shifted-generator anticommutation.
  Sectorwise P follows after resolving Π²; the full irreducible class stays open.
  This is not PT-symmetry, which requires an anti-linear PT operator.
