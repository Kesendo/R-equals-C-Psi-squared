  The (0,1) coherence block's dispersion: ω_k = 4J(1-cos(πk/N)), k=1..N-1

  The per-step sum grows with the step count (600 → 6000: ×10.0): it sums
  the eigensolver's per-step phase convention, not a geometric phase. The
  biorthonormal phase closed by <L(1)|R(0)> converges, to -3.998e-04 rad.
  Neither decides topology. The path is an open segment of an interval,
  so a phase is gauge-invariant only with a closing rule, and the closed
  value depends on that rule; a loop on an interval retraces itself.
  The block is complex symmetric (H real), so the biorthogonal connection
  vanishes: a loop in several γ would read 0 or π, π only around an
  exceptional point, and this path encircles none. The Berry test
  cannot decide here.

SUMMARY
========================================================================

Phase 1: the (0,1) coherence block is tight-binding with UNIFORM hopping.
  No alternating structure → no SSH topology.
  Localization profile matches the cos (Neumann) standing waves this
  phase computes, not the Dirichlet sin family, which belongs to F2b.

Phase 2: Chiral block structure exists (Π eigenspaces give
  off-diagonal L_c). At N=5 the off-diagonal blocks have FULL RANK;
  the N=4 zero singular values are the even-N centre modes at -Σγ.

Phase 3: the path is an open one-parameter segment, so no Berry phase can
  decide; a per-step phase sum grows with the step count.

Phase 5: the protection factor is continuous (its largest jump shrinks
  with the grid) and the slowest rate never closes → no sharp phase
  boundary. Each mode keeps its standing-wave profile; the γ profile
  selects which modes are slowest (center-heavy under edge sacrifice,
  center-dark under center sacrifice, all tied under uniform noise).

Phase 4: the center-localized fraction depends on what counts as the
  middle and on any tolerance; it is no topological invariant.

CONCLUSION: The localization [0.52, 0.63, 0.70, 0.63, 0.52] is
GEOMETRIC, not topological. It arises from standing wave patterns
on a 1D chain (cos (Neumann) eigenstates). The sacrifice zone
EXPLOITS this geometry by placing noise where fast modes live
(edges) and quiet where slow modes live (center). The chain
topology provides the mode structure. The noise provides the
selection pressure. No topological invariant protects anything.
