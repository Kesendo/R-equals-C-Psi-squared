the topology on its own.

On the path the cross-sector weight is zero to machine precision and
the per-sector weights are exact integers.  On the ring it is not:

What survives, on the path: the seat dependence is a sum of
per-sector contributions, each of them the commutant of that
sector's Hamiltonian intersected with the operators the dissipator
does not kill.  In the single-excitation sector H is nondegenerate

1, 3, 2, 2, 3, 1 = 12 where 1 + blind would give 10.  The reason is
NOT that the sector Hamiltonian is degenerate: on the uniform chain
popcount 2 and 3 are SIMPLE, and part 8(a2) below checks it exactly,
deg gcd(chi, chi') = 0 at N = 5, 6 and 7 in both.  So the obvious
sum rule is false and F4's question stays open.

THE CRITERION, which reproduces all of it.  H_SE on an open chain is
a Jacobi matrix and therefore simple; an eigenvector vanishes at a
site exactly when its eigenvalue is shared by the two principal
submatrices that site leaves behind.  So

    blind(j) = deg gcd( charpoly(H_left), charpoly(H_right) )

computed here in exact Fractions, no eigensolver.  Swept against the
exact GF(p) kernel over uniform, ramp, palindromic and pseudo-random
integer profiles:

  Heisenberg   (profile, seat) pairs tested: 330    mismatches: 0
  XY           (profile, seat) pairs tested: 330    mismatches: 0

Two corollaries, read off the criterion rather than measured.  On
the UNIFORM chain the shared factor is the cosine coincidence the
divisor law counts, which is why that law is exactly right there.
And a chain reflection-symmetric ABOUT SEAT j makes the two blocks
equal, so the gcd is the whole characteristic polynomial and
blind(j) = j.  That is sufficient at the ONE seat it speaks about
and says nothing about any other, so global reflection symmetry buys
the centre of an odd chain and nothing else.

THE FENCE IS BOOK-SPECIFIC, which is why both books are swept.
On HEISENBERG the failure is TOTAL, not partial: all 1682 zero-bond
pairs are wrong and all 316 zero-free pairs are right.  On XY the
same zero-bond set has 60 pairs the criterion still gets
RIGHT, while the 316 zero-free pairs are right on both books.

The reason is that the fence is not really about the zero bond; it is
about the DEGENERACY a zero bond forces.  On Heisenberg it always
forces one: each component contributes the one-magnon descendant of
its own ferromagnetic vacuum at the same eigenvalue, so two
components always repeat a level.  On XY there is no such term and a
cut chain can keep a simple spectrum.  Simplicity is NECESSARY there
and not sufficient, and that is COUNTED rather than asserted; the
four cells of the XY zero-bond half, and the Heisenberg ones beside
them because a column of zeros is the whole Heisenberg story:

       book  simple & right  simple & wrong  degen & right  degen & wrong
 Heisenberg               0               0              0           1682
         XY              60             342              0           1280

Read the XY row: the 'degenerate and right' cell is EMPTY, so every
pair the criterion gets right is simple, which is necessity; the
'simple and wrong' cell is not, which is why it is not sufficient.
On Heisenberg the two simple cells are BOTH empty, which is the
no-simple-spectrum claim above, counted.

The smallest case, seat by seat, so that 'the end seat' is not used
as a name for it:

   N = 3, bonds [0, 1], XY        :  measured [2, 1, 1]   criterion [0, 1, 0]

   On Heisenberg the two ends do not even agree with each other, so
   the cut is what the criterion cannot see, not the seat's position.
   The XY row is the smallest of the 60: at SEAT 1 the cut leaves two
   1x1 blocks with the same characteristic polynomial, deg gcd = 1,
   and that is the true count, so a zero bond leaves the criterion
   standing there.  It is the same arithmetic on both books; what
   differs is the diagonal the ZZ term adds.

WHAT THE DEPHASING ACTUALLY KILLS, because an earlier version of
this work said it 'kills every entry of rho that crosses the seat'.
It does not.  Z-dephasing at seat j kills rho_ab exactly when the
SEAT'S OWN bit differs between a and b, which in this sector means
exactly one of a, b IS the seat: it clears the seat's row and column
and touches nothing else.  The decay mask at N = 7, seat 3, in units
of gamma (0 = untouched, -2 = killed), exactly and by construction:

     0   0   0  -2   0   0   0
     0   0   0  -2   0   0   0
     0   0   0  -2   0   0   0
    -2  -2  -2   0  -2  -2  -2
     0   0   0  -2   0   0   0
     0   0   0  -2   0   0   0
     0   0   0  -2   0   0   0

   entry (0, 6), which CROSSES the seat:   untouched
   entry (2, 3), which TOUCHES the seat:   killed

So the seat does not decohere the two sides from each other, and a
surviving state is free to be coherent straight across it.  It is:
   the 3 blind modes at N = 7, seat 3, each as rho = |psi><psi|, sorted by energy:
     seat amplitude 1.80e-16   rho[0, 6] = -0.0538
     seat amplitude 2.49e-16   rho[0, 6] = -0.1746
     seat amplitude 5.90e-16   rho[0, 6] = -0.2716
   Every one of them is non-zero across the full length of the chain,
   and that is a THEOREM rather than these three numbers: on a Jacobi
   matrix no eigenvector can vanish at an END, since the three-term
   recursion would then drag the whole vector to zero.  So every blind
   mode of every zero-free profile carries a non-zero end-to-end
   coherence.  H_SE is simple here, so each value is fixed up to a sign
   the product cancels.  NOTE THE SCOPE: this is about the BLIND modes,
   not about every surviving state.  I/N survives too and its
   end-to-end entry is exactly zero.  One wave with a node at the
   watched place, not two worlds that cannot see each other.

THIS TABLE IS A NULL RESULT ABOUT THE PAIRS, and it took three
tries to say so.  The reading under test was that a non-adjacent
shared-neighbourhood pair (graph theory's FALSE TWINS) is what
carries the cross-sector weight.  The table refuses it on both
sides, and the first two summaries written for it were wrong.

NOT SUFFICIENT: the star has three such pairs at N = 4 and six at
N = 5, and carries no cross-sector weight at any seat.

NOT NECESSARY: the last row has no NON-ADJACENT shared-neighbourhood
pair at all (vertices 0 and 1 are ADJACENT with the same closed
neighbourhood, which is a different thing and is not what is counted)
yet it carries 6, 12, 6 at seats 2, 3, 4.  That is the row that ends
the reading, and it was found by a reviewer sweeping every connected
graph on five vertices, not by this script's own case list.

AND THE SEAT RULE POINTS BOTH WAYS, which is the sharpest of the
three.  On C4+pendant, one pair, the weight is ZERO at exactly that
pair's seats.  On K4 minus an edge, also one pair, the weight is
non-zero at exactly that pair's seats and zero everywhere else.  And
on C4 every seat lies in a pair and every seat carries 4.  No rule
in terms of the pairs survives all three.

What survives is only the open-chain statement of part 4: on the
HEISENBERG path the kernel is block-diagonal in popcount, and
elsewhere it need not be.  Not 'off the path', which part 8(b)
refutes by dropping the ZZ term and keeping the path.  Which systems
carry cross-sector stationary coherence is OPEN, it is not a question
about topology alone, and this table is the record of one reading
that failed.

THE FULL KERNEL BY SECTOR, EXACTLY, and two things it settles.

Part 4 took the full-space kernel by an SVD and stopped at N = 6.
Every (p, q) popcount block is ranked here instead, the diagonal ones
and the CROSS ones, so the whole 4^N kernel is measured and its split
is not assumed.  Every number in (a), (b) and (c) is an exact rank
with no eigensolver and nothing to tolerate; (a3) is the exception
and says so where it stands.

(a) The middle seat (N-1)//2 of the open chain, uniform J.  At ODD N
that seat is reflection-fixed and blind; at EVEN N it is neither, and
both are printed because the even rows are what decide WHY the sum
rule below survives where it does.

The two middle lists are the same numbers by two independent routes:
the pure-Python elimination at p = 2^61 - 1 and the numpy one at
p = 2^31 - 1.  THE DIAGONAL BLOCKS ONLY: the cross column is ranked
at p = 2^31 - 1 alone, and saying otherwise would overstate it.  Two
primes matter on the diagonal because a GF(p) rank can only be too
SMALL, so a kernel dimension read off it can only be too LARGE, and
one prime is a certificate with a probability attached.  They do not
matter on the cross blocks, for a better reason: a nullity can only
be reported too LARGE, so a measured nullity of ZERO forces the
rational nullity to be zero.  One prime settles an empty block.

THE CROSS COLUMN IS THE POINT.  The claim below is about the FULL
kernel, and a sum over diagonal blocks is not a full kernel unless
the cross blocks are empty.  They are, measured, on every row above.
Part 4 could confirm that only through N = 6, by an SVD; this reaches
N = 7, which is the first N where the two formulas differ at all.

The 'b^2+b' column is docs/CAUGHT_ERRORS.md's committed parenthetical
'kernel excess is b^2+b, not gcd', evaluated.  It agrees at N = 3 and
N = 5 and is WRONG at N = 7, where it says 20 and the exact answer is
18.  The even rows do not discriminate: b = 0 there, so the formula
says N+1 and every sector carries 1.  3(N-1) fits the three ODD rows,
and is printed only for them; three points are not a law and this is
not offered as one.  What is settled is that the committed formula is
false, at the smallest N that can tell.

AND THE EVEN ROWS ANSWER THE SUM RULE'S 'WHY'.  The natural guess is
(N+1) + sum_w blind_w, which holds at N = 3, 4 and 6 and fails at
N = 5 and 7.  An earlier version of the page said the surviving N
have no in-between sector.  They do: N = 4 has w = 2 and N = 6 has
w = 2, 3, 4, and the table shows each of them carrying 1.  What the
even rows lack is not the sector, it is the BLINDNESS: b = 0 at an
even chain's middle seat, and where nothing is blind every sector
carries 1 and any sum rule is trivially right.  The rule fails at
exactly the N where a blind middle seat and an in-between sector
exist together, which is N = 5 and N = 7 here.

(a2) AND THE MECHANISM IS NOT DEGENERACY.  An earlier version of
this script said the popcount >= 2 sector Hamiltonians are degenerate
and that this is where the excess comes from.  They are simple, and
that is checked EXACTLY rather than by a smallest gap: a matrix has a
simple spectrum iff its characteristic polynomial is squarefree, iff
deg gcd(chi, chi') = 0, computed here in Fractions.

  N  sector w   dim  deg gcd(chi, chi_prime)  simple
  5         2    10                        0     yes
  5         3    10                        0     yes
  6         2    15                        0     yes
  6         3    20                        0     yes
  7         2    21                        0     yes
  7         3    35                        0     yes

Heisenberg degeneracy is ACROSS popcount sectors, in the SU(2)
multiplets, not inside one.  That is a UNIFORM-chain statement, and
(a3) below carries reflection-symmetric profiles whose popcount-2 and
popcount-3 sectors DO have a doubled eigenvalue, so it is the PROFILE
that puts a degeneracy inside a sector.  On a SIMPLE sector the
count is the number of connected components of the sector's
eigenmodes under the dephased seat's occupation operator: rho commutes
with H_w, so it is diagonal in the eigenbasis, and the seat's
condition forces one common coefficient along every edge.  In the
single-excitation sector that operator is a rank-one projector, every
mode not vanishing at the seat fuses into one component and each
node-mode stands alone, which is part 2's 1 + blind.  A component is
NOT a blind state: at N = 5, popcount 2, nothing is blind and the
count is still 2.

(a3) THE HYPOTHESIS IS LOAD-BEARING.  Off a simple sector no single
eigenbasis need diagonalise every rho in the kernel at once, and the
component count then depends on the basis: it is a LOWER bound in
every basis, and the uniform chain above never shows the gap while a
palindromic profile at the same reflection-fixed centre does.  The
kernel and the simplicity degree below are exact; the component
counts are float, and what they exhibit is a basis effect.

chain                         w  deg gcd  simple  exact ker  components  re-bases  adapted
N = 5 uniform                 2        0     yes          2           2 one value        2
N = 5 palindrome [4,3,3,4]    2        1      NO          2           1 one value        2
N = 7 uniform                 3        0     yes          2           2 one value        2
N = 7 palindrome [4,3,4,4,3,4]  3        2      NO          2           1 one value        2

Both palindromes carry a doubled sector eigenvalue, and in the
SOLVER'S basis the component count comes out below the exact kernel
there.  Neither is a counterexample to the mechanism, and the last
two columns are why.

The 're-bases' column re-runs the count on 50 random re-bases of each
degenerate eigenspace and returns one value.  That value carries no
information about the mechanism.  The count is a LOWER bound in every
basis, so the question is what its MAXIMUM over eigenbases is, and a
maximum is attained on a measure-zero set of bases: a random draw
lands in the generic stratum, where the mode graph is maximally
connected and the count minimal, with probability one.  The test is
blind in exactly the direction the question runs.

The 'adapted' column fits the basis to n_seat inside each degenerate
eigenspace and reaches the exact kernel on both palindromes.  That
recipe is NOT the general prescription: it can fall short of the best
basis, and it is undefined when n_seat is itself degenerate on a
degenerate eigenspace.  The general statement is algebraic.  The
kernel is the commutant of A = <H_w, n_seat>; writing A's Wedderburn
blocks as (n_i, m_i) with sum n_i m_i = dim, the kernel is sum m_i^2
while the best achievable component count is sum m_i.  They agree
exactly when every m_i = 1, i.e. when the commutant is abelian.

That settles both rows with no solver at all: a multiplicity 2 costs
4, so a kernel of 1, 2 or 3 forces every m_i = 1 and the best basis
then realises the kernel as its component count.  Both exhibited
kernels are 2.  FOUR is the first kernel dimension at which a
multiplicity 2 fits, so the first at which the mechanism can fail
at all; the smallest failure exhibited here sits one above it.  The
star at
N = 4 with the HUB dephased has blocks (2,1) and (1,2) in the
single-excitation sector, so its kernel is 5 while no basis can give
more than 3 components.  The gap is sum m_i^2 - sum m_i, and it is
open only for the zero-free open chain, where none is exhibited
here either way.

The star witness, measured rather than asserted.  Four exact numbers
fix the block structure and a reader can redo the arithmetic:

case                           d  dim A  dim ker  blocks  best count
star N = 4, hub, w = 1         4      5        5       2           3
star N = 4, hub, w = 2         6      8        5       2           3

sum n_i m_i = d, sum n_i^2 = dim A, sum m_i^2 = dim ker, and the
block count b pin the (n_i, m_i) uniquely here: (2,1) and (1,2) at
w = 1, (2,2) and (2,1) at w = 2.  Both give sum m_i = 3 against a
kernel of 5, so no eigenbasis reaches the kernel and the undercount
is basis-free.  'best count' is that sum, solved from the four
numbers to its left rather than read off any basis.

These are reflection-symmetric profiles read at the reflection-fixed
centre, which is the setting of table (a), so the hypothesis has to
travel with the sentence.

spectrum to compare.

Read the table this way.  The deleted form matches the definition on
every row, the rows whose spectrum is NOT simple included: the two
triangle graphs, the star, the complete graphs, and every zero-bond
path, whose halves repeat each other.  The halves form is wrong on
exactly the zero-bond paths, which is part 6's fence.

So for the COUNT the fence belongs to the PHRASING and not to the
phenomenon.  Stated on the principal submatrix the criterion needs
no fence, no simplicity hypothesis and no chain; the chain is where
the cut matrix happens to fall into two pieces, which is what let
the criterion be written as a gcd of two halves in the first place.

The SPAN is a different story, and the last column is what the
chain's 'load-bearing twice' really covers: a zero bond does break
the span, but the zero bond is NOT the discriminator.  The counts
are book-specific and the tables ABOVE carry them:

    span failures    Heisenberg 8 of 20    XY 9 of 20

and the honest reading of them is CONNECTIVITY, not the bond list.
Counting failures 'with no zero bond' turns on whether a missing
edge is written as J = 0 or left out: 5 of the failures
are on CONNECTED graphs, the SAME ones on both books,

        complete K4
        complete K5
        star N = 5
        star N = 6
        two triangles bridged N = 6

while the zero-bond path [1,0,1], which is disconnected, HOLDS.  So
neither the zero bond nor the disconnection decides it.  What does:
dim ker L_SE(j) = 1 + blind(j) can BREAK only where the spectrum is
degenerate, and plenty of degenerate rows hold anyway: the rings, on
BOTH books; K4 minus an edge, degenerate and holding on the ZZ book
and simple on the XY one; and the isolated seat, degenerate on both,
holding on ZZ and BREAKING on XY.  So simplicity is
SUFFICIENT for the span and NOT necessary.  That is the hypothesis
the summary lines above point at.  On [1,1,0,1,1] at seats 1 and 4
the count is 4 and the kernel is 7.  The count generalises and the
kernel identity does not, so a reader carrying the fence-free
criterion to the kernel would be carrying it past the hypothesis it
needs.

ONE SEAT AGAINST A SUPPORT.  For a single seat, blind(j) = 0 forces
a one-dimensional kernel on ANY graph and needs no simplicity: it
says e_j is cyclic for H, so anything commuting with H and with the
seat's projector sends e_j to a multiple of itself and is therefore a
multiple of the identity.  For a SUPPORT of several seats that fails
without connectivity, and the smallest witness is a cut chain:

    N = 4 [1,0,1], gamma on {0, 2}   joint blind = 0, dim ker = 2
    N = 4 [1,0,1], gamma on {0, 3}   joint blind = 0, dim ker = 2
    N = 4 [1,1,1], gamma on {0, 2}   joint blind = 0, dim ker = 1

The connected chain gives 1 + 0, as the single-seat statement would;
the two disconnected pairs each keep their own scale and give 2 with
nothing blind to both seats at all.  So the one-seat form is a
theorem and the several-seat form carries a connectivity clause.

What this does NOT do: it does not decide which systems carry
cross-sector stationary coherence, which is what the open item asks.
It removes the typecheck failure that stood in the way of asking the
question on a graph at all.
