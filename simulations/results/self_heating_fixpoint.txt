Self-heating fixed point: there is none, and it is an identity rather than a search.

A fixed point would be an n_bar where Tr(H rho_steady) = Tr(H rho_Gibbs). Both
sides are known in closed form on this branch, so the question does not need a
sweep. The steady state is the product of the local targets diag(1-p, p) with
p = n_bar/(2 n_bar + 1), the same object the stationarity gate above pins, so

    Tr(H rho_steady) = (N-1) * <Z>^2 = (N-1) / (2 n_bar + 1)^2   >= 0,

while tr H = 0 exactly, so a Gibbs state at any beta > 0 has Tr(H rho_Gibbs) < 0.
The gap is a non-negative number minus a negative one. It cannot vanish.
